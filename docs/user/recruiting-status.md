# Update Status Cards

## Change a Stage
1. Select "Change stage".
2. Use the stage dropdown to select the new stage.
3. Use the staff dropdown to select which staff member is making the
   change.
4. Save the changes.
5. The stage will be updated with the new stage, who made the update,
   and a timestamp when it happened. 

## USNA Offers
- See details on any offers made to the recruit.
- Details include:
    - Who made the offer
    - When the offer was made

## Update Offers from other Schools
1. Select "+ Add offer".
2. Fill out all the provided fields.
3. Save the change.
4. The new offer will be added to the table of offers from other
   schools.
- See all offers made by OTHER schools to the recruit.
- *Duplicate Warning*: Will generate a warning if duplicate offers are
  entered.

## Add a Visit
1. Select "+ Add visit".
2. Fill out all the provided fields.
3. Save the change.
4. A new visit will be added to the table of USNA visits.
